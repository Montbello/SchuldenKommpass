### Animationen
```css
/* Performance-optimierte Animationen */

  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* GPU-beschleunigt */
.element {
  will-change: transform;
  transform: translateZ(0);
}
```
